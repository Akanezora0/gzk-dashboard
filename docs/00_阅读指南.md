# 阅读指南

这套文档面向第一次接手本项目的同事和 AI 工具。它同时说明“研究要回答什么”“当前已完成什么”“代码与数据在哪里”“怎样继续开发”。当前基线：**2026-11-05**。

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| [01 项目背景与研究主线](01_项目背景与研究主线.md) | 技术供给/需求两侧、方法论、词表和八个问题 | 首次接手 |
| [02 当前成果与研究计划](02_当前成果与研究计划.md) | 已完成的库、综述、分析、展示，下一步方向 | 理解任务优先级 |
| [03 数据资产与统计口径](03_数据资产与统计口径.md) | 来源、数量、年份、关系和分母区别、缺口 | 改数字/字段/指标前 |
| [04 Dashboard页面与内容约定](04_Dashboard页面与内容约定.md) | 各路由、设计基线、共享交互、内容限制 | 修改页面前 |
| [05 代码结构与数据更新](05_代码结构与数据更新.md) | 页面文件、生产脚本、输入和更新方式 | 接口/数据更新前 |
| [06 本地运行与服务器部署](06_本地运行与服务器部署.md) | 安装、快照/live、构建、部署边界、排错 | 启动或发布 |
| [07 多端协作与验收](07_多端协作与验收.md) | 分支/PR、AI交接、验收清单和版本追溯 | 每个开发任务 |
| [08 展示快照与接口](08_展示快照与接口.md) | 包内资料、API查询语义、刷新流程及当前遗留项 | 扩展接口或更新快照 |

只改样式时，读04/05与目标组件即可，不必重新分析全部数据库。要做新研究指标时，先读01–03并确认样本和关系，不从静态图表反推资金因果贡献。

原服务器项目仍有 sources、ingestion、retrieval、analysis、dashboard、collaboration 等完整流程；这个仓库交付 Dashboard 和展示所需的资料，不包含全文原件、巨型数据库、模型或收费采集密钥。源码与原项目对应关系在 `SOURCE_MAP.json`；包内展示版本在 `snapshot/manifest.json`。
